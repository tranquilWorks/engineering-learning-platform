# DSP aggregate review specification

This is the authorized later-batch design, not completed assessment evidence.
It follows the initial semantic-repair group and requires a separate approved
contract. Preserve all 84 repaired numerical models, independent reference

## Competency and assessment structure

| Domain | Existing lessons | Cumulative evidence task |
| --- | --- | --- |
| Sampled signals and systems | P01–P10 | Predict alias frequency and quantify a reconstruction/filtering failure using correctly labeled sample rate and units. |
| Spectral and complex processing | P11–P20 | Distinguish bin spacing, leakage, physical resolution and noise; reconstruct an IQ tone through downconversion, calibration and frequency/phase estimation. |
| Modulation, adaptation and statistical inference | P21–P28 | Trace pulse shaping/matched filtering and channel correction; compare repeated trials, ROC operating points and estimator assumptions. |
| Radar waveform, range and Doppler | P29–P40 | Carry delay/phase signs and units from waveform through compression, range resolution, PRF ambiguity and integration. |
| Clutter and adaptive detection | P41–P52 | Explain clutter assumptions, training/guard contamination, CFAR variants, valid cells and empirical false-alarm uncertainty. |
| Reports and tracking | P53–P60 | Separate clustering, association, filtering, confirmation/coasting/deletion and maneuver model selection; diagnose a failed association from reports and histories. |
| Arrays and adaptive processing | P61–P68 | Relate element spacing, calibration, steering, covariance conditioning and signal-subspace assumptions to beam/DOA/STAP evidence. |
| FMCW, MIMO and micro-Doppler | P69–P74 | Resolve beat-frequency signs, range–velocity coupling and virtual-array timing; explain the time/frequency resolution tradeoff. |
| Coherent imaging and passive/adaptive processing | P75–P83 | Connect phase history, compression, migration, aperture sampling and focus; distinguish SAR, ISAR, passive cross-ambiguity and STAP assumptions. |
| End-to-end pulsed-radar capstone | P84 | Trace waveform, receiver calibration, compression, range–Doppler, CFAR, clustering and track lifecycle through the retained scene and named failure/recovery. |

The map must name prerequisites, target learners, exclusions, cross-course
handoffs, competency-to-module relationships and assessment identifiers. Derive
the module count from the 84 actual identities and validate an acyclic prerequisite
graph; do not manufacture breadth by adding lesson inventory.

Every lesson must expose its competency/checkpoint in the browser using an
explicit authored projection, alongside its existing concept/prediction/controls/
plots/checks. Assessments need concrete tasks, expected reasoning, dimensional
relations, evidence to record and a rubric that distinguishes a plausible picture
from a justified result. Use the retained independent scenarios and actual metric
names when a quantitative threshold is appropriate. Self-checking text is not a
record of a learner passing an assessment.

P84 is a pulsed-radar processing/tracking capstone. It does not execute all the
array, FMCW, imaging or passive-radar branches; those require separate cumulative
checks using their relevant existing lessons. Do not claim a single universal
radar integration from the final lesson title.
