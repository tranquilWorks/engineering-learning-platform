## Changed invariants

- Manifest dispatch now requires exact integer version 1 and produces stable
  file/version-aware failures.
- Typed structures are closed by concrete runtime, control, lesson-block, and
  widget variants; only named carriers remain free-form.
- Catalog promotion validates every trusted Python default result, semantic
  references, identities, and paths atomically.
- Course/module content digests bind exact accepted bytes; Git absence is
  explicit; runtime source identity covers uncommitted executable bytes.
- Run requests bind the module digest displayed to the learner, and results/UI
  expose schema, content, Git/null, platform, and runtime identities.
- One command deterministically generates all JSON Schema and TypeScript
  derivatives and rejects byte drift.
- Runtime loading suppresses course bytecode writes and rejects changed inputs,
  non-finite values, unordered sets, non-string keys, reserved fields, malformed
  envelopes, stale revisions, timeouts, and oversized API results.
- Catalog promotion is synchronized across readers: discovery leaves the prior
  snapshot available, candidate validation is isolated, and a failed candidate
  is rolled back before waiting readers can proceed.
- YAML mappings with unhashable keys are rejected through the stable, file-aware
  catalog error boundary instead of escaping as an internal `TypeError`.

## Independent system-risk review repairs

- High: candidate catalog state was assigned before default-result validation,
  allowing a concurrent API reader to observe a course that was subsequently
  rejected. Added a catalog re-entrant lock around candidate promotion,
  validation, and rollback, guarded all public catalog reads, and added a
  deterministic two-thread regression fixture proving a failed candidate is
  never observable.
- Medium: the unique-key YAML loader performed dictionary membership on an
  unhashable YAML key and leaked `TypeError`; admin reload would return an
  internal server failure rather than the stable contract diagnostic. Converted
  that case to `yaml.constructor.ConstructorError` and extended the malformed
  YAML behavioral fixture.
