# MATLAB reference slot

This directory is intentionally reserved for the original MATLAB experiment, retained figures, and golden vectors.

The platform runtime must not claim numerical equivalence merely because the Python lesson looks similar. A migration batch should:

1. run the approved MATLAB experiment;
2. export selected deterministic vectors and metrics;
3. compare them with the Python runtime within declared tolerances;
4. retain the exact MATLAB version, toolboxes, commands, and results.
